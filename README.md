## 设计资源

项目设计稿：[Figma · 177](https://www.figma.com/design/i4Xsv9T30MQY7ySoExu4Fi/177?node-id=0-1)。

后续需要下载项目的设计资源时，默认从此 Figma 文件获取对应节点资源。

图片资源下载规范：

- 从 Figma 按 **3×（3 倍图）** 导出 PNG，直接导出目标倍率。
- 下载后自动进行**无损压缩**，再放入项目资源目录。
- 压缩保持导出图的像素尺寸、颜色和透明通道不变，并校验解码后的像素一致；若压缩后文件未变小，保留原文件。
